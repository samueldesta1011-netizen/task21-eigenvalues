Task 21: Eigenvalues and Eigenvectors Solver in C
This project is a C library and console application for finding eigenvalues and eigenvectors of real square matrices.
Methods Used
Jacobi rotation method: For symmetric matrices.
QR algorithm: For general matrices (real eigenvalues).
Power method: For finding the dominant eigenvalue and its vector.
Inverse iteration: For finding eigenvectors given a known eigenvalue.
How to Build
Make sure you have gcc and make installed.
make
